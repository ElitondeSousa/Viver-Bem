# Viver Bem – Cuidado na Terceira Idade

Landing page do projeto extensionista **Viver Bem**, com orientações de saúde, segurança e direitos para pessoas idosas, familiares e cuidadores.

**Equipe:** Eliton de Sousa Pereira e Guilherme Landin

## Conteúdo

- Dicas de cuidado no dia a dia (alimentação, hidratação, atividade física, medicamentos, quedas e saúde mental)
- Proteção contra golpes
- Sinais de alerta e telefones úteis (192, 193, 100, 188)
- Direitos da pessoa idosa (Lei nº 10.741/2003)
- Perguntas frequentes e contato

## Como abrir

Abra o `index.html` no navegador, mantendo a pasta `imagens` ao lado. O site é feito só com HTML, CSS e JavaScript, sem instalação.
